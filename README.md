# 彩票选号与历史数据分析助手 (Lottery Helper)

基于 **Python + PyQt6** 构建的跨彩种桌面端选号与历史数据分析工具，支持 **双色球**、**大乐透** 与 **福彩3D**，提供历史数据采集、概率统计、确定性 Top-N 排序推荐、模拟购彩兑奖以及策略回测功能。

> **免责声明**：彩票每次开奖均为独立随机事件，历史统计仅反映经验分布特征，不能预测未来开奖结果。本工具仅作数据分析与娱乐参考，请理性购彩。

---

## 核心功能

1. **多采种规则引擎**
   - 内置 **双色球**（红球 `01-33` 选 6 + 蓝球 `01-16` 选 1）、**大乐透**（前区 `01-35` 选 5 + 后区 `01-12` 选 2）、**福彩3D**（百/十/个位 `0-9` 直选）。
   - 采用配置驱动的分区模型，便于扩展其他数字彩种。

2. **历史数据采集适配器**
   - **在线公开接口同步**：内置中国福彩网（双色球、福彩3D）与中国体彩网（大乐透）采集适配器。
   - **本地导入**：支持导入 `.csv` 与 `.xlsx` 格式历史开奖文件。
   - **离线模拟数据**：内置模拟数据生成器，方便无网络环境下快速演示与测试。

3. **概率与统计分析**
   - 统计指定期数窗口（近 30 / 50 / 100 / 200 期或全部）内各号码的出现频次、历史经验概率 vs 理论概率、当前遗漏、平均遗漏、最大遗漏、欲出度及综合评分。
   - 绘制频次对比柱状图与理论期望线，并汇总和值区间、奇偶比、大小比与跨度等历史形态分布。

4. **智能选号与号码评估**
   - 支持 **确定性 Top-N 排序推荐**（默认，相同数据与参数下输出完全一致的最高评分排序组合）与 **加权随机采样** 两种模式，支持 4 种权重策略（综合评分、均衡随机、追热选号、防冷回补）及和值区间过滤。
   - **一键复制**：支持 **复制文字** 与 **复制图片**，仅输出具体分区颜色与球号。
   - **自选号码评估**：输入自选号码即可查看其历史形态分布与经验契合度诊断。

5. **模拟购彩与开奖兑奖**
   - 支持将推荐号码或自选号码记录为下一期模拟购彩（支持自定义期号与投注倍数）。
   - 真实开奖后同步或导入最新数据，系统自动匹配期号并计算中奖等级与奖金；支持单选或多选删除购彩记录。

6. **历史滚动回测**
   - 按时间顺序使用开奖前窗口数据训练权重并验证后续期次的命中分布。

## 项目结构

```text
lottery-helper/
├── main.py                     # 应用入口
├── requirements.txt            # Python 依赖列表
├── LotteryHelper.spec          # PyInstaller macOS 打包配置
├── src/
│   ├── core/
│   │   ├── models.py           # 彩种规则、开奖记录、统计与购彩数据模型
│   │   └── registry.py         # 彩种注册表（ssq / dlt / fc3d）
│   ├── data/
│   │   ├── adapters.py         # 历史数据采集适配器（在线接口 / CSV / Excel / 模拟）
│   │   └── storage.py          # SQLite 持久化层（默认存储于 ~/.lottery-helper/lottery.db）
│   ├── analysis/
│   │   └── engine.py           # 频次、遗漏、形态分布与号码评估引擎
│   ├── strategy/
│   │   ├── generator.py        # 确定性 Top-N 排序与加权随机选号引擎
│   │   ├── prize.py            # 奖级判定与自动兑奖结算
│   │   └── backtest.py         # 滚动历史回测引擎
│   └── ui/
│       └── main_window.py      # PyQt6 桌面端主界面
└── tests/
    └── test_core_and_engine.py # 单元测试
```

## 快速开始

### 1. 安装依赖并从源码运行

建议使用 Python 3.9+：

```bash
pip3 install -r requirements.txt
python3 main.py
```

### 2. 数据存储位置

应用默认将 SQLite 数据库保存至当前用户主目录下的隐藏文件夹中：

```text
~/.lottery-helper/lottery.db
```

### 3. 打包为 macOS 桌面应用（`.app`）

安装 PyInstaller 后执行：

```bash
pip3 install pyinstaller
python3 -m PyInstaller --noconfirm LotteryHelper.spec
```

打包完成后可在 `dist/LotteryHelper.app` 找到独立应用程序，双击即可运行。
